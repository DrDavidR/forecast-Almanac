FORMULA: RBC = (W_plus - W_minus) / (W_plus + W_minus)

IMPLEMENTATION AUDIT:
  compute_manuscript_measurements.py (M5, LD2011):
    r = (pos_ranks - neg_ranks) / total_r
    pos_ranks = sum of ranks where d > 0 (comparator better) = W_plus
    neg_ranks = sum of ranks where d < 0 (L0 better) = W_minus
    r = (W_plus - W_minus)/(W_plus + W_minus) ← CANONICAL ✓
    Status: CORRECT

  run_mda2_wiki_daily.py (Wiki) — BEFORE CORRECTION:
    rbc = 1 - (4 * stat) / (n * (n + 1))
    where stat = scipy min(W_plus, W_minus)
    → gives (W_minus - W_plus)/(W_plus + W_minus) when L0 favorable
    → positive when L0 favorable ← WRONG SIGN

  run_mda2_wiki_daily.py (Wiki) — AFTER CORRECTION:
    w_plus  = sum of ranks where d > 0
    w_minus = sum of ranks where d < 0
    rbc = (w_plus - w_minus) / (w_plus + w_minus)
    Status: CORRECTED ✓
